The model

Crowd density estimation, designed for real scenes.

SATARK uses CSRNet, a convolutional neural network built for estimating the number of people in crowded images. It creates a density map rather than trying to draw a box around every individual, which makes it more useful when people overlap or are far from the camera.

01 — Input

Upload a crowd image

Use a clear JPG, PNG, WEBP, AVIF, or other supported image. The image is prepared at an adaptive size so the model can preserve useful scene detail.

02 — Analysis

Estimate density

The VGG16-based network extracts visual features. Squeeze-and-Excitation blocks help it emphasize useful crowd patterns across areas with varied clothing, lighting, and headwear.

03 — Result

Review the scene

The density values are summed into an estimated head count. You receive the count, a visual density map, and a safety classification for faster review.

What you receive

Results at a glance

Density map

Safety zone
A simple classification derived from the estimated crowd density.

Accuracy and care
